# Контент пен API келісімі

Мәртебе: талқылауға арналған бастапқы келісім. Админ панель мен көрермен қолданбасы бірдей дерек пішімін қолдануы керек. Видео сервисі таңдалғанша, интеграция осы құжаттағы бейтарап API арқылы жүргізіледі.

## 1. Негізгі нысандар

### Series

- `id`: UUID
- `slug`: URL үшін бірегей атау
- `status`: `draft` немесе `published`
- `genre`: жанр коды
- `coverUrl`: мұқабаға арналған URL
- `translations`: `ru` және `kk` тілдеріндегі `title`, `description`

### Episode

- `id`: UUID
- `seriesId`: сериалдың `id` мәні
- `number`: серия нөмірі
- `status`: `uploading`, `processing`, `ready` немесе `failed`
- `videoAssetId`: видео сақтау сервисіндегі активке сілтеме
- `durationSeconds`: өңделген видеоның ұзақтығы
- `translations`: `ru` және `kk` тілдеріндегі `title`, `description`
- Қазіргі іске қосылымда төлем жоқ; сериялар тегін көрсетіледі. Болашақтағы монетизацияны осы келісімге қазір қоспаймыз.

## 2. Админнің видео жүктеу ағыны

1. Админ кірген қолданба `POST /api/admin/video-uploads` endpoint-іне серия/серия нөмірі мен файл метадеректерін жібереді: `fileName`, `contentType`, `sizeBytes`.
2. Сервер админ рөлін тексеріп, видео сервисінен уақытша жүктеу адресін алады. Жауап: `uploadId`, `uploadUrl`, `expiresAt`.
3. Браузер видеоны сол уақытша адреске тікелей жүктейді. Видео байттары GitHub-қа, браузер bundle-ына немесе SQL кестесіне салынбайды.
4. Видео сервисінің webhook-ы серверге өңдеу күйін хабарлайды. Сервер webhook қолтаңбасын тексеріп, `Episode.status` мәнін `processing`, `ready` не `failed` деп жаңартады.
5. Админ тек `ready` болған серияны жариялай алады. Көрермендерге тек жарияланған сериалдар мен `ready` сериялар беріледі.

Видео сервисінің құпия кілттері серверде ғана сақталады. Браузерге service key берілмейді.

## 3. Көрермен API-і

### Каталог

`GET /api/catalog?lang=kk&genre=rom`

Тек `published` сериалдар мен дайын серияларды қайтарады. `genre` міндетті емес; `lang` әдепкіде `ru`.

### Сериал беті

`GET /api/series/{slug}?lang=kk`

Сериал мәтіндерін сұралған тілде және дайын сериялар тізімін қайтарады.

### Ойнату адресі

`POST /api/playback-token` body: `{ "episodeId": "..." }`

Сервер серияның `ready` екенін тексеріп, видео сервисіне сәйкес ойнату адресін қайтарады: `{ "playbackUrl": "...", "expiresAt": "..." }`. Қазіргі кезеңде барлық жарияланған серия тегін; төлем не entitlement тексерісі жоқ. Егер таңдалған видео сервисі қорғалған URL талап етпесе, уақытша токен орнына оның ойнату адресі берілуі мүмкін.

## 4. Қол жеткізу және сақталатын деректер

- Сериялық видео активі Git репозиторийде сақталмайды; репозиторийде код, схема және конфигурация үлгілері ғана болады.
- Серия/серия мәтіндері мен видео активінің ID-сі дерекқорда сақталады.
- Админ жазу және жариялау әрекеттерін сервер тексереді. Көрермен API-і тек жарияланған/дайын материалды оқиды.
- Нағыз кілттер `.env` ішінде болады; `.env` GitHub-қа жіберілмейді.

## 5. Біріктіру реті

1. Видео сақтау провайдерін және осы өрістерді админ әзірлеушісімен растау.
2. Backend/API осы келісім бойынша іске қосу.
3. Админ панелін upload API-мен жалғау.
4. Каталог пен плеерді `GET /api/catalog`, `GET /api/series/{slug}` және `POST /api/playback-token` endpoint-теріне жалғау.
5. Бөлек Git branch-тарда жұмыс істеп, Pull Request арқылы `main` тармағына біріктіру.
