# Microdrama platform

Mobile-first free viewing interface, organized as a Next.js App Router project.

## Start locally

1. Install Node.js 20.9 or newer.
2. Run npm install in this folder.
3. Run npm run dev.
4. Open http://localhost:3000.

The original standalone HTML and sample MP4 remain at the project root. The Next.js version uses public/videos/flower-sample.mp4. All catalog data is local for now; payment, sign-in, database, and admin tools are not connected.
